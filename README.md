# Smartphone Data Analysis & Price Prediction

Exploratory and predictive analysis of a dataset of 15,000 smartphones, using **pandas** and **numpy** for data wrangling, **scikit-learn** for price prediction, and **Plotly** / **Matplotlib + Seaborn** for visualization.

## Dataset

`smartphones.csv` — 15,000 rows × 25 columns, including `price`, `brand_name`, `ram`, `storage`, `battery_capacity`, `camera_mp`, `screen_size`, `refresh_rate`, `release_year`, `network_support`, `operating_system`, `fingerprint_sensor`, `dual_sim`, among others.

## Scripts

- **`analise_smartphones.py`** — exploratory data analysis (EDA) with pandas/seaborn/matplotlib. Prints descriptive statistics and text insights, and saves three static PNG charts.
- **`analise_preditiva.py`** — predictive analysis with scikit-learn (Linear Regression, Random Forest, Gradient Boosting). Trains models to predict smartphone price and projects market trends up to 2032, exporting five interactive Plotly HTML charts.

Run either script from the repository root:

```bash
python analise_smartphones.py
python analise_preditiva.py
```

## Chart Explanations

### Interactive charts (Plotly, generated by `analise_preditiva.py`)

| File | What it shows |
|---|---|
| `01_projecao_preco.html` | Historical average smartphone price by release year, fitted with a **Linear Regression** trendline projected forward to 2032, with a shaded confidence band (±1.5 std of residuals). |
| `02_importancia_features.html` | Horizontal bar chart of **feature importances** from the Random Forest price model — shows which specs (RAM, release year, storage, encoded categoricals, etc.) drive price the most. |
| `03_real_vs_previsto.html` | Scatter plot comparing **actual vs. predicted price** for a 500-sample test subset, for both Random Forest and Gradient Boosting models, against a "perfect prediction" reference line (R² shown per model). |
| `04_tendencias_specs.html` | Multi-panel projection (up to 2032) of average RAM, battery capacity, camera resolution, refresh rate, storage, and 5G adoption rate over time, each fitted with its own linear trend. |
| `05_bubble_marcas.html` | Bubble chart of the top 15 brands: **average price** (x-axis) vs. **average camera resolution** (y-axis), bubble size = number of models, colored by brand. |

### Static charts (Matplotlib/Seaborn, generated by `analise_smartphones.py`)

| File | What it shows |
|---|---|
| `graficos_visao_geral.png` | 2×2 panel: top 10 brands by model count, price distribution boxplot for the top 6 brands, operating system market share (pie chart), and average price by release year. |
| `correlacao.png` | Correlation heatmap across numeric specs (price, battery, RAM, storage, camera, screen size, refresh rate, fast charging, weight, thickness). |
| `ram_storage.png` | Side-by-side bar charts of the RAM (GB) and internal storage (GB) distributions across all devices. |

## Key Findings

- Random Forest slightly outperforms Gradient Boosting for price prediction (lower MAE, higher R²).
- RAM and release year are the strongest price predictors — camera resolution and refresh rate matter less.
- Prices are projected to grow moderately through 2032, driven by faster chips and higher-refresh-rate displays.
- RAM and storage are expected to roughly double in mid-range segments by 2032.
- 5G adoption is projected to exceed 80% of global releases before 2030.
